# Protocolo Colaborativo - Unidad 1: Estructuras de Datos

## Universidad de Cartagena - CTEV
**Asignatura:** Estructuras de Datos  
**Semestre:** 1  
**Lenguajes seleccionados:** Python 3 y JavaScript (Node.js)  

---

## 1. Descripción del Proyecto
Este módulo corresponde al desarrollo del **Protocolo Colaborativo** para la Unidad 1. Siguiendo las directrices de la cátedra:
- **No se utiliza Java** (exclusivo para el protocolo individual).
- La actividad se implementa en **dos lenguajes de programación diferentes**: **Python** y **JavaScript**, permitiendo un análisis comparativo entre tipado dinámico, sintaxis y manipulación de estructuras en memoria.
- Cada ejercicio se implementa de forma independiente en ambos lenguajes.
